# 日语字幕来源备选

按剧种/来源选路线，不必逐站走完。站点覆盖和版权政策会变化，每次都要核对剧名、年份、季数、集数和**日语原文字幕**内容；只保存精选例句用于个人学习。本技能只提取日语词条，绝不用翻译字幕反推日语词汇。

## 日语剧集 / 电影 / 动画（日语原声 + 日语字幕）

1. **NHK ドラマ・プレミアム**：<https://www.nhk.jp/drama/>。日本公共放送的剧集点播，含大量现当代日剧与历史剧；很多提供日语字幕或文稿，是规范日常/书面日语的好来源。
2. **Netflix 日语剧 / 动画**：如 *静かな海のあいだに*、*First Love 初恋の唄*、*全裸監督*、*今際の国のアリス*、*僕のヒーローアカデミア* 等。若用户提供 Netflix 页面或本地日语字幕文件，优先使用用户可访问的日语原字幕；登录、地区限制或 DRM 导致无法读取时，不能假装已拿到台词，请用户贴字幕文本或上传 `.srt/.vtt/.ass/.smi`。
3. **日本电影 / 电视台剧**：如 *小偷家族*、*晩秋*、*勝手にふるえてろ*、*TBS 日曜劇場* 等。用日文片名 + `SRT` / `字幕` 搜索。
4. **アニメ（动画）**：台词口语化、敬语与年轻人用语丰富，适合日常表达与听力；用日文标题 + `Scripts` / `台本` / `字幕` 查找。

## 日语播客 / 新闻 / 教学（适合日常与考试词汇）

1. **NHK ニュース・やさしい日本語**：<https://www3.nhk.or.jp/news/easy/>。慢速、用言易懂的日语新闻，附假名与音频，适合 N4–N2 词汇与阅读。
2. **Satori（サトリ）**：<https://satorireader.com/>。带逐句解析的日语播客与新闻，适合 N3–N1，含语法与文化注解。
3. **日本語の森（Nihongo no Mori）**：<https://nihongonomori-nihongo.com/>。JLPT 各等级免费教学视频与文稿，适合按考试范围筛词。
4. **日本人の日本語（Slow Japanese）**：慢速日语播客，附文稿，适合 N4–N2 听力与口语。

## 字幕数据库（兜底）

1. **OpenSubtitles**：<https://www.opensubtitles.org/>。把字幕语言设为 Japanese/日本語，再按日文剧名、年份、season/episode 过滤；多版本时以集数、分辨率/发行组和字幕行数判断是否对应目标视频。
2. **Kitsunekko / ニコニコ大百科字幕**：日语字幕社区，可用日文片名搜索动画/剧集日语 SRT。
3. **Subscene / YIFYsubs**：搜索时务必选择 **Japanese** 语言标签，不要选 “Japanese (Romaji)” 或翻译字幕。

## 通用处理

- 已知站点的单集正文可以通过 `https://r.jina.ai/` 预处理，但先确认原页面真的含连续日语对白；代理返回导航页、验证页或错误页时立即放弃该候选。
- 用户提供字幕文件时直接解析，不再联网。支持 `.srt`、`.vtt`、`.ass`、`.ssa`、`.smi` 和纯文本台词；先去时间码、标签和重复行，再保留日语对白。
- 日语汉字与假名必须保持原样，不做 ASCII 化；汉字词常带送假名，提取时按原句实际词形填 `targets`（如 `預ける` 在句中被说成 `預けた` 时设为 `["預けた"]`）。注意长音、促音、拗音（`っ` `ゃ` `ゅ` `ょ`）和浊音/半浊音（`゛` `゜`）的准确性。

## 成功判断与止损

成功必须同时满足：

1. 页面或文件身份匹配剧名、年份、季数和集数；
2. 内容是日语连续对白，或字幕文件包含时间码和日语对白行；
3. 能从中抽出多条不重复的完整日语原句。

HTTP 200、页面字数多、搜索摘要或剧情简介都不算成功。请求使用 `--connect-timeout 8 --max-time 20 -fL`；每个站点最多换一次搜索词，最多尝试三类来源。所有下载和引用都遵守站点条款与版权边界，不下载整集视频，不绕过登录、付费或地区访问控制。
